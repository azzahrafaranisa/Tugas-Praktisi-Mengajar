# Analisis Data dan Prediksi Keterlambatan Pembayaran
Studi kasus ini membahas analisis data bisnis pada PT Maju Bersama untuk memahami pola penjualan, keuntungan, dan keterlambatan pembayaran. Analisis dilakukan menggunakan Python dengan bantuan library Pandas, NumPy, dan Matplotlib untuk mengolah data serta menyajikan hasil analisis. Selain itu, algoritma Random Forest diterapkan untuk memprediksi keterlambatan pembayaran berdasarkan data yang tersedia. Tahapan pengerjaan meliputi pemahaman bisnis, pemahaman dan persiapan data, analisis deskriptif, pemodelan prediktif, serta evaluasi model dan penyusunan rekomendasi bisnis.
