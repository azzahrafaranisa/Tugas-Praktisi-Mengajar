# Materi 6 - Klasifikasi Penyebab Deforestasi Menggunakan CNN

Studi kasus ini membahas klasifikasi lima kategori penyebab perubahan tutupan hutan, yaitu pertanian, pertambangan, penebangan kayu, pembangunan jalan, dan gangguan alam. Model Convolutional Neural Network (CNN) dilatih menggunakan citra simulasi berukuran 32 × 32 piksel. Data dibagi menjadi data pelatihan dan pengujian, kemudian model dievaluasi menggunakan akurasi, classification report, dan confusion matrix. Library yang digunakan adalah NumPy untuk pengolahan data numerik, TensorFlow untuk membangun dan melatih CNN, Matplotlib untuk visualisasi, serta Scikit-learn untuk pembagian data dan evaluasi. Studi kasus ini merupakan simulasi pembelajaran dan belum menggunakan citra satelit Sentinel-1 atau Sentinel-2 asli.
