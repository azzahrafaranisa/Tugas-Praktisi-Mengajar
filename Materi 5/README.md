# Materi 5 - Dashboard Visualisasi Data Penjualan

Studi kasus ini membahas analisis penjualan untuk mengetahui produk terlaris, total pendapatan, dan perubahan pendapatan setiap bulan. Data diolah menggunakan Python dan Pandas, kemudian divisualisasikan dengan Matplotlib dalam bentuk grafik penjualan dan pendapatan bulanan. Pengguna dapat memilih kategori produk melalui terminal untuk melihat ringkasan dan grafik sesuai pilihannya. Materi ini menerapkan prinsip Data Visualization dan interaksi pengguna untuk membantu memahami informasi penjualan serta mendukung pengambilan keputusan bisnis.
