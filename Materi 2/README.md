# Materi 2 - Simulasi Evakuasi Bencana
Studi kasus ini membahas simulasi evakuasi bencana untuk menghitung jarak masyarakat menuju titik aman terdekat dan memperkirakan waktu perjalanan. Simulasi menggunakan Python dengan 100.000 posisi masyarakat secara acak dan tiga titik aman. Perhitungan dilakukan menggunakan metode Python Loop dan NumPy untuk membandingkan waktu komputasi. Hasil simulasi ditampilkan dalam bentuk tabel dan grafik berdasarkan beberapa skenario jumlah masyarakat. Library yang digunakan adalah NumPy untuk perhitungan numerik, Pandas untuk pengolahan data, dan Matplotlib untuk visualisasi. Simulasi ini bertujuan untuk pembelajaran dan bukan sebagai acuan evakuasi bencana nyata.
